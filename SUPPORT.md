# Dukungan

Dukungan komunitas tersedia melalui:

1. GitHub Issues untuk bug dan permintaan fitur.
2. GitHub Discussions untuk pertanyaan umum.
3. Forum web dan Matrix untuk diskusi.

Sebelum melapor, baca `docs/FAQ.md` dan `docs/INSTALL.md`.

Laporan bug harus menyertakan versi, arsitektur, edisi, dan log yang
relevan.
