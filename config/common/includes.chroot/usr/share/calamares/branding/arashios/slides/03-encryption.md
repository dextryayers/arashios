# Enkripsi

Enkripsi LUKS2 tersedia pada langkah partisi. Passphrase diminta sekali
saat boot, atau dapat dikunci otomatis dengan kunci yang tersimpan di partisi
EFI untuk pemakaian desktop tanpa password.

Pastikan passphrase dicatat di tempat aman. Data yang terenkripsi tidak dapat
dipulihkan tanpa passphrase.
