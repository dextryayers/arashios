# ADR-012: Cakupan legacy i386

- Status: Accepted
- Tanggal: 2026-10-21
- Pengganti: kosong

## Konteks

Sebagian perangkat lama masih memakai CPU 32-bit atau firmware 32-bit. Debian 12 menyediakan i386, tetapi tidak semua desktop dan tool mendukung arsitektur ini dengan baik.

## Keputusan

i386 dibangun untuk edisi LXQt sebagai default dan XFCE sebagai varian ringan. Cinnamon tidak dibangun untuk i386. Target minimum adalah CPU 686 dengan PAE, RAM 1 GB, dan ruang disk 12 GB. Boot UEFI 32-bit tidak dijamin pada v1.

## Konsekuensi

1. Matriks ISO i386 terdiri dari dua artefak: LXQt default dan varian XFCE.
2. Kernel memakai flavour 686-pae.
3. Beberapa tool keamanan modern mungkin tidak tersedia.
4. QA i386 membutuhkan perangkat atau VM 32-bit.
5. Dokumentasi menjelaskan batasan dengan jelas.

## Alternatif yang ditolak

| Alternatif | Alasan ditolak |
|---|---|
| Menghapus i386 | Menghilangkan pengguna perangkat lama |
| Semua edisi untuk i386 | Beban QA dan ukuran tidak sebanding |
| Amd64 dengan userland 32-bit | Bukan skenario yang didukung secara resmi |
