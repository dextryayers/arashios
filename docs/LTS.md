# Dukungan Jangka Panjang

## 1. Kebijakan

1. Setiap major didukung 12 bulan.
2. Rilis terakhir major mendapat 6 bulan tambahan.
3. Debian 12 LTS berakhir Juni 2028.

## 2. Kanal

1. stable untuk produksi.
2. edge untuk pengguna awal.
3. nightly untuk kontributor.

## 3. Rotasi Kunci

Rotasi kunci mengikuti `docs/KEY-ROTATION.md`. Kunci darurat disimpan
di dua lokasi fisik terpisah.

## 4. Cadangan

1. Snapshot repository disimpan.
2. Artefak rilis disimpan permanen.
3. Log build disimpan bersama artefak.
