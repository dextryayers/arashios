# Pertanyaan yang Sering Diajukan

## 1. Apakah ArashiOS gratis?

Ya. ArashiOS dirilis di bawah GPL-3.0-or-later untuk kode dan
CC-BY-SA-4.0 untuk aset.

## 2. Apakah ada telemetry?

Tidak. Tidak ada koneksi otomatis saat boot.

## 3. Apakah Secure Boot didukung?

Belum pada v1. Secure Boot dijadwalkan pada pasca v1.

## 4. Bagaimana cara memperbarui?

Gunakan `apt update` dan `apt upgrade`. Update major memerlukan
konfirmasi pengguna.

## 5. Di mana melaporkan bug?

Gunakan GitHub Issues dengan template yang tersedia.

## 6. Apakah dapat dual boot dengan Windows?

Ya. Lihat `docs/INSTALL.md` dan `docs/RECOVERY.md`.
