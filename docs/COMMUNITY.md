# Komunitas dan Dukungan

ArashiOS membangun komunitas yang terbuka dan terdokumentasi.

## 1. Kanal

1. Forum web untuk diskusi umum.
2. Matrix untuk komunikasi cepat.
3. GitHub Discussions untuk ide dan roadmap.
4. GitHub Issues untuk bug dan permintaan fitur.

## 2. Template

Template issue berada di `.github/ISSUE_TEMPLATE/`. Template pull request
berada di `.github/PULL_REQUEST_TEMPLATE.md`.

## 3. Kode Etik

Proyek mengikuti Contributor Covenant 2.1. Lihat `CODE_OF_CONDUCT.md`.

## 4. Dukungan

1. Dokumentasi di `docs/`.
2. FAQ di `docs/FAQ.md`.
3. Panduan instalasi di `docs/INSTALL.md`.
4. Panduan recovery di `docs/RECOVERY.md`.

## 5. Tata Kelola

Maintainer utama mengelola rilis. Perubahan scope memerlukan revisi plan.md
dan persetujuan maintainer.

## 6. Rilis Komunitas

Kontributor dapat membangun ISO sendiri dengan `build.sh`. Artefak
komunitas tidak ditandatangani dengan kunci rilis.
