# Lokalisasi dan Aksesibilitas v2

## 1. Lokalisasi

1. Terjemahan tambahan selain en_US, id_ID, ja_JP.
2. Validasi layout teks panjang.
3. Pengujian font fallback.

## 2. Aksesibilitas

1. Peningkatan screen reader.
2. Mode kontras tinggi.
3. Navigasi keyboard penuh.

## 3. Pengujian

Setiap rilis memeriksa:

1. Locale tampil benar.
2. Orca dapat dijalankan.
3. Skala font 100, 125, 150 persen.
