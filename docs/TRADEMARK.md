# Kebijakan Merek Dagang

## Nama

Nama `ArashiOS` dan varian stilasi `ARASHIOS` adalah tanda proyek. Penggunaan yang diizinkan:

1. Merujuk proyek asli secara faktual.
2. Menyebut kompatibilitas, misalnya `berbasis ArashiOS`.
3. Ulasan, tutorial, dan liputan media.
4. Distribusi ISO resmi tanpa modifikasi.

Penggunaan yang memerlukan izin:

1. Menjual produk dengan nama ArashiOS.
2. Menggunakan nama untuk layanan hosted.
3. Menggunakan logo pada merchandise.
4. Mengklaim afiliasi atau dukungan resmi.

## Logo

1. Logo tidak boleh diubah proporsi, warna, atau bentuknya.
2. Logo tidak boleh dipakai sebagai ikon aplikasi pihak ketiga.
3. Logo harus memiliki ruang kosong minimal setengah tinggi mark.
4. Logo tidak boleh ditempatkan pada latar yang mengurangi kontras.

## Fork

Fork yang didistribusikan wajib:

1. Mengganti nama produk.
2. Mengganti logo dan identitas visual.
3. Menghapus klaim resmi.
4. Mempertahankan notice lisensi.
5. Menyatakan bahwa fork tidak didukung proyek asli.

## Debian

Debian adalah merek dagang Software in the Public Interest, Inc. ArashiOS menggunakan Debian sebagai basis dan tidak diklaim sebagai proyek resmi Debian. Materi promosi harus menyatakan hubungan tersebut secara akurat.
