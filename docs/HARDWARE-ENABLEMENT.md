# Dukungan Hardware Lanjutan

## 1. Cakupan

1. Driver WiFi baru.
2. Dukungan GPU.
3. Update firmware via fwupd.

## 2. Proses

1. Tambahkan firmware ke daftar paket.
2. Uji pada perangkat nyata.
3. Dokumentasikan kompatibilitas.

## 3. Laporan

`arashios-hardware-report` mengumpulkan informasi hardware untuk
diagnosis. Laporan tidak dikirim otomatis.
