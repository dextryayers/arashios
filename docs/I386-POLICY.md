# Kebijakan i386

## 1. Status

i386 merupakan tier 3 pada v1. Edisi LXQt default dan XFCE alternatif.

## 2. Evaluasi

Setiap rilis utama mengevaluasi:

1. Coverage tool T0 minimal 85 persen.
2. Ketersediaan kernel 686-pae.
3. Permintaan pengguna.

## 3. Deprecation

Jika coverage di bawah 85 persen selama dua rilis berturut-turut,
i386 dapat diturunkan menjadi build komunitas.

## 4. Komunikasi

Keputusan deprecation diumumkan minimal 6 bulan sebelum berlaku.
