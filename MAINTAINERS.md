# Maintainer

## 1. Tanggung Jawab

1. Menjaga kualitas rilis.
2. Mengelola repository dan mirror.
3. Meninjau pull request.
4. Menangani laporan keamanan.

## 2. Kontak

Laporan keamanan dikirim sesuai `SECURITY.md`.

## 3. Succession

Jika maintainer utama tidak tersedia, maintainer cadangan mengambil
alih dengan persetujuan dua kontributor senior.
