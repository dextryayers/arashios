# Tata Kelola

## 1. Peran

1. Maintainer utama mengelola rilis dan repository.
2. Kontributor mengirim pull request.
3. Reviewer menyetujui perubahan.

## 2. Keputusan

Perubahan scope, arsitektur, atau jadwal wajib dicatat sebagai revisi
plan.md dengan tanggal dan alasan.

## 3. Rilis

Hanya maintainer yang dapat menandatangani dan mempublikasikan artefak.

## 4. Kunci

Kunci rilis disimpan pada media offline. Rotasi mengikuti
`docs/KEY-ROTATION.md`.
